# 抓取预算监测器

从访问日志估算站点抓取资源使用情况，帮助优化服务器容量、页面响应和百度蜘蛛的抓取体验。

## 核心功能
- 按站点、目录和时间窗口统计抓取量
- 观察错误率、平均耗时和慢请求
- 找出低价值 URL 对抓取资源的占用
- 提供 JSON 结果供监控系统接入

## 使用
```powershell
python tool.py --demo
python tool.py --input sample.csv --json
```
抓取预算是观测指标，不是可以被人为制造的配额；优化重点应放在稳定内容、合理内链和可靠响应上。
